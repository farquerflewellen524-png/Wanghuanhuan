# 规培生培养系统

这是一个面向住院医师规范化培训的前端原型，覆盖病例/化验单录入、诊断推演、指南量表入口、风险并发症提示、诊疗计划、聊天式追问，以及最近 10 次记录调用。

## 功能模块

1. **输入病例化验单**：支持患者基本信息、主诉、现病史/既往史/用药史、查体、化验/影像/心电图等结构化录入。
2. **诊断推演**：根据关键词规则给出初步诊断、鉴别诊断和可能忽略的诊断，用于教学演练。
3. **指南与量表链接**：内置国内外指南入口与常用风险量表链接，点击后可查看网页或 PDF 资源。
4. **风险与并发症**：针对病例主题提示需要关注的风险、并发症和升级处置信号。
5. **完整诊疗计划**：生成从急危重评估、检查验证、治疗、复盘到预防并发症的计划清单。
6. **随时提问聊天框**：可围绕检查、ICU、用药、治疗等问题获得教学式回复。
7. **最近 10 次使用记录**：通过浏览器 `localStorage` 保存最近 10 个病例，支持一键载入。

> 注意：本项目仅用于医学教学与规培训练，不替代执业医师判断、上级医师复核或真实临床决策。

## 本地运行

```bash
npm run start
```
